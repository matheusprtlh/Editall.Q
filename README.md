# Editall.Q

**Monitoramento inteligente de licitações públicas com IA e automação.**

O **Editall.Q** é um projeto para facilitar a identificação de oportunidades de contratação pública relevantes para empresas da construção civil. A proposta é reduzir o trabalho manual de acompanhar editais e usar inteligência artificial para apoiar a priorização de oportunidades.

## Como funciona

O sistema foi concebido para consultar dados públicos do **Portal Nacional de Contratações Públicas (PNCP)**, organizar informações das licitações e avaliar sua relevância para o setor. A arquitetura também prevê alertas para acompanhar as oportunidades identificadas.

## Tecnologias

- **n8n** — automação e orquestração.
- **JavaScript** — tratamento de dados.
- **API do PNCP** — consulta de licitações.
- **Claude AI** — análise de relevância.
- **PostgreSQL** — armazenamento e controle de registros (planejado).
- **Evolution API** — notificações por WhatsApp (planejado).
